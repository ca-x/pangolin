## Method notes

- Deletion behaviour was reproduced directly against SQLite with the repository's DDL and triggers
  (`sqlite3` 3.53.4): deleting a model whose price is referenced by `usage_logs` aborts with
  `used price versions cannot be deleted`; deleting an unused provider cascades providers, models,
  prices, associations and credentials to zero rows with no error. No Rust test covers either path.
- `/v1/models` visibility was read, not exercised: `src/orchestration/mod.rs:121-169` filters by
  enabled model+provider, key mapping, allowed endpoints and non-empty candidate generation.
- Rows 1-8 are `parity`/`refuted` so the list is not padded: the pricing data model, price
  versioning, catalog subscriptions, routing preview, association core, transformation core, price
  component kinds and the provider preset catalog are all genuinely implemented.
