# Console-wide UX parity: ranked extras and cross-cutting rules

Re-derived from the current code (Pangolin `HEAD`, 2026-09-21) because the earlier
chat-only review was never saved. AxonHub is used as a read-only behaviour
reference; no code or assets were copied.

Scope: the five ranked extras from the earlier review (bulk selection, in-channel
probe, credential entry, log filters, dismissible onboarding) plus the
cross-cutting rules in `AGENTS.md` → Frontend conventions.

Status vocabulary: `parity` = an operator cannot tell the two apart in a
meaningful way; `gap` = the capability exists but is materially weaker; `feature-build`
= nothing exists on the Pangolin side; `refuted` = the earlier claim does not hold.
